# Kalenderprofile 2.0.4

**Release-Kandidat · Installer- und Dokumentationskorrektur**

## Behoben und verbessert

- Veraltete sichtbare Versionsangabe (`V2.0.1`) und übernommene Beta-15-Hinweistexte aus dem Installer entfernt.
- Installer vollständig neu gestaltet: klare Gliederung, responsive Darstellung, besser lesbare Texte und klar unterscheidbare Installationswege.
- **Drag-and-drop:** Bookmarklet-Schaltfläche direkt in die Browser-Lesezeichenleiste ziehen.
- **Manuelle Installation:** vollständige Bookmarklet-Adresse in einer auswählbaren Codebox, Schaltfläche „Code kopieren“, Clipboard-API und Fallback über markierten Text.
- **Einheitliche Datenquelle:** Drag-and-drop-Link und Copy/Paste-Code kommen aus demselben eingebetteten Bookmarklet. Kein zweiter Quellcode im Installer.
- Neue gepflegte Vorlage `install/installer-template.html`: Der Build erzeugt die vollständige Installationsdatei deterministisch aus der Vorlage und der Versionsnummer des Quellcodes, statt nur einen Link in einem veralteten HTML-Dokument auszutauschen.
- Statische Konsistenzprüfungen und echte Chromium-Tests auf Desktop- und Mobilbreite sowie für beide Kopierwege ergänzt.

## Kompatibilität

- Der eigentliche Kalenderprofile-Funktionsumfang, UI innerhalb Nextcloud, Speicherformat und die CalDAV-Logik bleiben gegenüber 2.0.3 unverändert.
- Keine externen Laufzeitabhängigkeiten; Installation auch aus lokal geöffneter HTML-Datei möglich.
- Bestehende Profile und Einstellungen bleiben erhalten; das Bookmarklet kann als neues Lesezeichen installiert oder gegen das bisherige ausgetauscht werden.
- Die serverseitige CalDAV-Sortierung mehrerer Kalender ist weiterhin nicht atomar.

## Installation

Nach Veröffentlichung das Installer-HTML aus den GitHub-Release-Assets lokal in Chrome oder Edge öffnen. Anschließend den blauen Link in die Lesezeichenleiste ziehen oder den vollständigen Link über die Codebox kopieren und als Lesezeichenadresse speichern.

**Hinweis:** Dies ist die Dokumentation eines vorbereiteten Release-Kandidaten, keine Bestätigung einer bereits erfolgten Veröffentlichung oder Live-Abnahme.
