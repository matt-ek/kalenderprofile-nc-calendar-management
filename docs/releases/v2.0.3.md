# Kalenderprofile 2.0.3

**Release-Kandidat · 05.11.2026**  
**Art:** Stabilisierung und Absicherung, keine neuen Funktionen

## Änderungen

- **CalDAV-Regressionstests:** Neuer Playwright-Test mit isolierter, simulierter Nextcloud-/DAV-Umgebung. Geprüft werden die reine Leseprüfung ohne serverseitige Schreibvorgänge, fehlende und ungültige DAV-Zuordnungen, abgelehnte Schreibbestätigung sowie ein Fehler nach einer teilweise wirksamen Serveränderung mit Rücknahmeversuch.
- **Freigabesicherung:** Die erweiterten Browser-Tests sind Bestandteil der verpflichtenden GitHub-Actions-Qualitätsprüfung; ein fehlgeschlagener Test blockiert das Release.
- **Generische Veröffentlichung:** Die Release-Pipeline verarbeitet künftig explizite SemVer-Tags statt hart kodierter Versionsnummern und startet nicht mehr automatisch durch Änderungen an der Pipeline auf main.
- **Reproduzierbarkeit:** Build, JavaScript-Quellen, Bookmarklet-URL und Installer müssen übereinstimmen; versionierte Installationsdatei, Quellarchiv und SHA-256-Prüfsummen werden im Release bereitgestellt.
- **Versionspflege:** Versionskennung 2.0.3 in Quelltext, Bundle, Bookmarklet und Installer; der Release-Konsistenzcheck ermittelt die Version künftig dynamisch.
- **Dokumentation:** Verbindliche Qualitäts- und Kompatibilitätsmatrix, dokumentierte Risiken und Release-Freigabe.

## Kompatibilität und Daten

- Unveränderte Funktionen, UI und Bedienungsabläufe gegenüber 2.0.2.
- Unveränderte technische Speicher-IDs, JSON-Schema 1, Datenmigration und CalDAV-Logik.
- Bestehende persönliche Einstellungen müssen nicht erneut importiert werden.
- Keine neue Laufzeitabhängigkeit; der Installer enthält weiterhin das vollständige Bookmarklet.
- **CalDAV-Sortierung über mehrere Kalender ist weiterhin nicht atomar.** Bei einem Fehler wird ein Rücknahmeversuch ausgeführt, der nicht in jedem realen Fehlerfall erfolgreich sein kann.

## Installation (nach Veröffentlichung)

Unter [Releases](https://github.com/matt-ek/kalenderprofile-nc-calendar-management/releases) das Asset `kalenderprofile-v2.0.3-installation.html` herunterladen, lokal in Chrome oder Edge öffnen und den Bookmarklet-Link in die Lesezeichenleiste ziehen. Das bestehende Lesezeichen kann ersetzt werden. Zusätzlich wird `SHA256SUMS.txt` zur Integritätsprüfung ausgeliefert.

## Qualitätsstatus

Automatisierte Build-, UI- und simulierte CalDAV-Tests werden in GitHub Actions ausgeführt. Die [Release-QA](../RELEASE_QA_2.0.3.md) unterscheidet aktuelle CI-Ergebnisse von ausstehenden echten Nextcloud-/Browser-Abnahmen.

**Wichtig:** Diese Release Notes auf dem Entwicklungsbranch sind zunächst ein Entwurf. Ein offizielles GitHub-Release 2.0.3 darf erst nach den Qualitätsgates und einem geprüften Tag veröffentlicht werden.
